# WalkieDohi

WalkieDohi는 별도 메신저 서버를 둘 수 없는 폐쇄망 환경에서 Windows PC 간 메시지와 파일을 주고받기 위한 WPF 기반 메신저입니다.

기존 쪽지 형태의 사용성을 메신저에 가깝게 개선하는 것을 목표로 합니다.

## 주요 기능

- 1:1 채팅
- 그룹 채팅
- 텍스트, 이미지, 파일 전송
- 친구 목록 관리
- 채팅 로그 저장 및 이전 로그 불러오기
- 트레이 아이콘 및 자동 시작
- 이미지/PDF 미리보기
- 간단한 부가 도구와 미니게임

## 기술 스택

- C#
- WPF
- .NET Framework 4.7.2
- Newtonsoft.Json
- System.Data.SQLite
- WebView2
- ClosedXML

## 설계 메모

### MessageEntity와 ChatMessage를 분리한 이유

`MessageEntity`는 TCP 송수신에 사용하는 데이터 형식입니다. 기존 사용자와 신규 사용자 사이의 메시지 호환성을 유지하기 위해 전송 DTO는 가능한 한 안정적으로 유지합니다.

`ChatMessage`는 화면 표시와 로컬 저장에 사용하는 모델입니다. UI 표현, 표시 이름, 방향, 파일 경로 같은 클라이언트 내부 상태를 다룹니다.

### 그룹을 미리 만들어야 하는 이유

이 프로그램은 중앙 서버가 없는 P2P 구조입니다. 그룹 초대나 나가기 같은 상태 변경을 서버가 보관해주지 않기 때문에, 그룹원이 프로그램을 꺼둔 상태에서는 변경 사실을 즉시 알릴 수 없습니다.

이 문제 때문에 현재 구조에서는 그룹을 미리 만들고, 그 그룹 정보를 기준으로 대화하는 방식을 사용합니다.

## 현재 개선 우선순위

자세한 내용은 [개발 계획도](./Docs/개발계획도.md)에 정리합니다.

- 자동 시작 최소화 상태에서도 메시지 수신이 동작하도록 개선
- 전송 실패 상태를 UI와 저장소에 반영
- 채팅 로그를 SQLite 기반 로컬 DB에 저장
- MessageId 기반으로 중복 수신과 중복 저장을 방지
- IP 중심 식별 구조를 사용자 UUID 중심으로 개선
- 수신 파일 저장 경로와 중복 파일명 처리 개선
