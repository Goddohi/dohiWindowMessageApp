# 중분류
- Views
  - Windows(창,페이지) 
- ViewModels
  - 일부 Windows및 UserContorls의 ViewModel
- UserContorls
  - UserContorl(UC) 파일 
- Entity 
  - 엔티티 클래스
- Data 
  - 응용프로그램이 돌아가는 동안 데이터 저장 파일 

  > Data와 ViewModels의 차이점 
  > Data : 객체 단 하나로 데이터를 가지고 있음 (싱글톤과 비슷한 느낌)
  > ViewModels : 각 View,UC의 객체마다 데이터를 가지고 있기 위한 용도 (근본적인 ViewModel이 이런용도는 아니라서 적어뒀습니다.)

# 대분류 - 도메인

## Core
- 인터페이스 및 기준 클래스

## Util
- 공용 작업함수
## Commons
- 공용 Views 혹은 메인 데이터

## AppResource
- 어플리케이션 모든 리소스 (사용자에게 복사 하는 건 따로 복사)
### AppResource- Styles 
- (복사하지않음)
- 어플리케이션 스타일 소스
### AppResource- Libs 
- (사용자 exe옆에 복사)
- 대부분 사용되는 dll
### AppResource- Plugins 
- (사용자 exe옆에 복사)
- 특별한 창에 사용 되는 dll (e.g. viewer)
### AppResource- NativeDlls
- (사용자 exe옆에 복사)
- 빌드할때 무조건 exe옆에 둬야할 dll들(빌드할때 적용x)
### AppResource- Assest
- (사용자에게 폴더 경로 그대로 복사)
- 로고디자인

## Users
- 사용자의 설정 관련

## Games
- 게임 파일 

## Friends
- 친구 데이터 관련  

## Groups
- 그룹 데이터 및 그룹 생성

## ChattingRooms
- 채팅방

## Packets
- 송수신관련 파일 
### Packets - Messages
- 송수신 파일중 메세지파일
