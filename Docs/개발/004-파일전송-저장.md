# 수신 파일 저장 경로와 중복 파일명 개선

- 상태: 대기
- 우선순위: 1차 안정화
- 관련 영역: 파일 전송, 파일 저장, 사용자 데이터

## 왜 고려했는가

수신 파일은 사용자가 나중에 다시 열 수 있어야 하며, 같은 이름의 파일이 와도 기존 파일을 잃지 않아야 합니다.

현재는 고정 경로에 원래 파일명 그대로 저장하므로 권한 문제와 덮어쓰기 문제가 생길 수 있습니다.

## 현재 원인

- 수신 파일 저장 위치가 `C:\WalkieDohi\ReceivedFiles`로 고정되어 있습니다.
- 파일명 중복 방지 처리가 없습니다.
- 파일명 안전화 처리가 부족합니다.
- 파일 자동 저장 방식이라 사용자가 다운로드 여부를 선택할 수 없습니다.

## 해결 방향

- 저장 위치를 `%APPDATA%\WalkieDohi\ReceivedFiles` 하위로 이전합니다.
- 파일명을 안전화합니다.
- 같은 이름이 있으면 `(1)`, `(2)` 같은 중복 방지 이름을 생성합니다.
- 장기적으로는 자동 저장 대신 사용자 확인 후 다운로드하는 구조로 변경합니다.

## 완료 조건

- 권한 문제 없이 사용자 프로필 하위에 파일이 저장됩니다.
- 같은 파일명을 여러 번 받아도 기존 파일을 덮어쓰지 않습니다.
- 채팅 로그의 파일 경로가 실제 저장 위치와 일치합니다.
