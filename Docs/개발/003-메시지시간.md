# 파일/이미지 메시지 시간 정보 누락 수정

- 상태: 대기
- 우선순위: 1차 안정화
- 관련 영역: 메시지 모델, 채팅 로그 재로드

## 왜 고려했는가

채팅 기록은 시간 순서가 신뢰되어야 합니다. 파일이나 이미지 메시지의 시간이 재로드 시점으로 바뀌면 대화 흐름을 이해하기 어려워집니다.

## 현재 원인

텍스트 메시지는 생성자에서 전달받은 시간을 저장하지만, 파일/이미지 메시지는 전달받은 timestamp를 실제 `Timestamp` 속성에 반영하지 않는 흐름이 있습니다.

## 해결 방향

- `ImageMessage`, `FileMessage` 생성자에서 `Timestamp = timestamp`를 명시합니다.
- 저장된 과거 로그 중 시간이 누락된 데이터는 기존 기본값을 유지하되, 새 로그부터 정확히 저장합니다.
- 재로드 시 메시지 순서가 timestamp 기준으로 안정적인지 확인합니다.

## 완료 조건

- 파일/이미지 메시지를 보낸 뒤 앱을 재시작해도 시간이 유지됩니다.
- 텍스트, 이미지, 파일 메시지의 시간 처리 방식이 동일합니다.
- 기존 로그가 깨지지 않습니다.
