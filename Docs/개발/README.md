# 개발 진행 목록

이 폴더는 개발 진행 항목과 항목별 판단 근거를 모아두는 곳입니다.

각 항목 문서는 다음 내용을 기준으로 정리합니다.

- 왜 고려했는가
- 현재 원인
- 해결 방향
- 완료 조건
- 진행 기록

## 진행 목록

| 상태 | 우선순위 | 항목 | 상세 문서 |
| --- | --- | --- | --- |

| 대기 | 1차 안정화 | 전송 실패 상태를 UI와 저장소에 반영 | [002-전송실패-상태.md](./002-전송실패-상태.md) |

## 진행 규칙

- 사용자 체감 문제가 큰 안정화 작업을 먼저 처리합니다.
- 기존 사용자 데이터 호환성을 깨는 변경은 마이그레이션 계획을 먼저 문서화합니다.
- 빠른 안정화 패치와 장기 구조 개선이 다를 경우 둘을 분리해 기록합니다.
- 완료된 항목은 해결 방식과 남은 한계를 문서에 남깁니다.
