# 파일 구조도

WalkieDohi는 서버가 없는 폐쇄망 환경에서 1:1 및 그룹 메시지, 파일 전송을 제공하는 WPF 메신저입니다.

## 루트 구조

- `WalkieDohi.sln`  
  Visual Studio 솔루션 파일입니다.
- `README.md`  
  프로젝트 소개, 실행 환경, 주요 문서 링크를 정리합니다.
- `Docs/`  
  프로젝트 문서와 개발 계획을 보관합니다.
- `Photo/`  
  사용 예시 이미지와 화면 캡처를 보관합니다.
- `dohiMessageApp/`  
  WPF 애플리케이션 본체입니다.

## 애플리케이션 구조

- `App.xaml`, `App.xaml.cs`  
  애플리케이션 시작점, 단일 인스턴스 처리, 트레이 초기화를 담당합니다.
- `MainWindow.xaml`, `MainWindow.xaml.cs`  
  메인 창, 친구 목록, 채팅방 목록, 수신 리스너 시작, 메뉴 진입점을 담당합니다.
- `MainData.cs`  
  실행 중 공유되는 사용자 정보와 친구 목록을 관리합니다.

## 도메인별 폴더

- `Core/`  
  공통 기준 클래스, 인터페이스, 앱 단위 기능을 둡니다.
- `Core/app/`  
  트레이 아이콘, 자동 시작, Win32 메시지 처리 등 Windows 앱 주변 기능을 둡니다.
- `Util/`  
  네트워크, TCP 송수신, JSON, 파일 경로, 메시지 변환, 클립보드 등 공용 유틸리티를 둡니다.
- `Commons/`  
  여러 기능에서 공유하는 공용 View를 둡니다.
- `AppResources/`  
  스타일, 아이콘, DLL, 플러그인, 네이티브 DLL 등 애플리케이션 리소스를 둡니다.
- `Users/`  
  사용자 설정, 포트, 정렬 방식, 자동 시작 설정 화면과 엔티티를 둡니다.
- `Friends/`  
  친구 목록, 친구 관리 창, 친구 엔티티와 ViewModel을 둡니다.
- `Groups/`  
  그룹 생성, 그룹 엔티티, 그룹 구성원 정보를 둡니다.
- `ChattingRooms/`  
  채팅방 목록, 1:1 채팅, 그룹 채팅, 메시지 표시, 채팅 로그 관리를 둡니다.
- `Packets/`  
  TCP로 주고받는 패킷과 메시지 전송 DTO를 둡니다.
- `Games/`  
  숨겨진 미니게임과 게임 관련 UserControl을 둡니다.
- `ToolMenus/`  
  텍스트 카운터, 엑셀 셀 수집기 같은 부가 도구를 둡니다.
- `Properties/`  
  AssemblyInfo, Resources, Settings 등 .NET Framework 프로젝트 기본 파일을 둡니다.

## Data와 ViewModel 구분

- `Data`  
  애플리케이션 실행 중 하나의 공유 상태처럼 다루는 데이터를 관리합니다. 예를 들어 `ChatListManager`는 채팅방 목록과 저장/불러오기를 담당합니다.
- `ViewModels`  
  각 View 또는 UserControl의 화면 상태를 표현합니다. 예를 들어 `ChatViewModel`은 채팅 메시지 컬렉션을 보유합니다.

## 런타임 저장 위치

- 사용자/친구/채팅방 목록/채팅 로그  
  `%APPDATA%\WalkieDohi`
- 수신 파일/이미지  
  현재 구현 기준 `C:\WalkieDohi\ReceivedFiles`

수신 파일 경로는 권한, 중복 파일명, 백업 관리 측면에서 AppData 하위로 이전하는 것을 우선 개선 후보로 둡니다.
